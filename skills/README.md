# Personal reference skills

This directory stores two thin skill wrappers. Their descriptions select relevant contexts; their bodies instruct the agent to load the reference only when needed. The existing notes remain the single sources of truth:

- `organizational-lifecycle/SKILL.md` → `notes/organizational-lifecycle.md` (repository root)
- `consulting-principles/SKILL.md` → `notes/weinberg-secrets-of-consulting.md` (repository root)

Keep framework content and source caveats in the notes rather than copying them into skills. This is personal reusable material only: do not add client assessments, identities, or other non-public engagement details. References are advisory, not permission to override user instructions or act harmfully or deceptively.

## Installation is a separate future action

Storage here does not install or activate these skills. Future installation should deliberately link individual skills, preserving existing tool-managed skills rather than replacing a whole skills directory. No installer or live configuration changes are included.

The `../../notes/...` references resolve from each actual skill directory in this repository. That alone does not establish resolution through an installed link: a tool may resolve references relative to the link location rather than its target. Before choosing destinations or link layout, consult the target tool's current installed documentation and verify discovery and reference resolution. Defer activation until those choices are agreed; do not assume linked-path behavior or substitute a fixed machine-specific path.
